# Claims matrix (paper v2)

Every nontrivial claim the v2 manuscript may make, with the artifact that supports it and the conditions under which it holds. Paths are relative to the repository root at tag `v0.3.0` (commit `78bdf9d`, the squash merge of PR #10). The Commit column names the `research/v2` commit that introduced the behaviour or last changed it; those commits are not reachable from `mainline` or the tag, and are fetched with `git fetch origin pull/10/head` (head `1d1e400`). A claim with no row here is not to be made, and a claim is to be made only with the conditions its row states.

Corrected on 2026-10-26 against the `v0.3.0` artifacts (issue #13). C26–C28 were wrong against the committed data, many rows stated guarantees without the setup they need, and L6–L13 were missing. The figures in C24–C33 were checked against each scenario's `summary.json` and per-seed `runs.csv` under `results/`, and against re-runs of the harness with extra per-step counters.

Legend for the "Kind" column: **S** security boundary, **M** mechanism/state, **T** statistical, **E** experimental result, **L** limitation (a claim about what is *not* established).
