# Reproducibility appendix

Everything below is offline. No API key, no network call, no real side effect.

## Code identity

- Repository: `https://github.com/jasoneplumb/exe-auth-ctrl-loop`
- Branch and commit the results were generated at: `research/v2`, `c238787` (manifest regenerated at that commit in `18dae89` with an identical canonical hash). The docs in `docs/paper-v2/` were added after; they do not affect any artifact.
- Released lineage: `v0.1.0` = `f070e01` (DOI 10.5281/zenodo.21983062), `v0.2.0` = `b266eb7` (DOI 10.5281/zenodo.22730700). Concept DOI 10.5281/zenodo.21983061. Design disclosure DOI 10.5281/zenodo.21894658. **No tag, release, or DOI exists for v2 at the time of writing.**

## Environment used for the committed artifacts

- Python 3.14.4, macOS (`macOS-26.6.2-x86_64`). CI additionally runs the test suite on Python 3.10 and 3.13 (Ubuntu); the simulation was not run there.
- Runtime dependencies as resolved: `anthropic==1.11.0`, `openai==3.26.0`, `jsonschema==4.26.0`, `pydantic==2.13.5`. Development: `pytest==9.1.1`, `ruff==0.16.10`, `mypy==2.4.0`, `types-jsonschema==4.26.0.20261006`. The simulation imports only the standard library and this package; the provider SDKs are imported but never called.
- Randomness: `random.Random(seed)` per run, with the controller's audit RNG seeded as `seed * 7919 + 1`. The clock is simulated (`T0 = 2026-01-01T00:00Z` plus one minute per step). No `secrets`-generated identifier reaches any canonical artifact.

## Clean-room procedure

```sh
git clone https://github.com/jasoneplumb/exe-auth-ctrl-loop
cd exe-auth-ctrl-loop
git checkout 18dae89                     # or the tagged release once one exists
python3 -m venv .venv && . .venv/bin/activate
python -m pip install -e '.[dev]'

ruff check .                             # expected: All checks passed!
mypy src                                 # expected: no issues found in 12 source files
pytest -q                                # expected: 195 passed
python examples/example.py && python examples/denials.py && python examples/mcp_demo.py

python -m experiments.run --all --output /tmp/repro      # ~4 minutes
python - <<'EOF'
import json
a = json.load(open("results/manifest.json"))
b = json.load(open("/tmp/repro/manifest.json"))
assert a["canonical_hash"] == b["canonical_hash"] == \
    "2e9dc58974affce7aca80d2e93322d18defb94956d98682d5f62212881ccbf1a"
assert a["files"] == b["files"]
print("reproduced")
EOF
```

If the canonical hash differs, something in `src/` or `experiments/` changed since `c238787`, or the platform's `math.lgamma` differs in its last bits (the bisection is deterministic; a cross-platform ulp difference in `lgamma` could in principle move a lower bound at the 1e-15 level and change a trace where a decision sits exactly on the threshold). No such difference has been observed; the hash has reproduced on the generating machine across three independent full runs (two in the Step 08 gate, one in the Step 09 gate).

## What each artifact is

See `experiments/README.md` "Artifacts and manifest". In short: `results/<scenario>/config.json` is the exact input, `runs.csv` one row per seed, `trace.jsonl` the first seed's per-step record, `summary.json` the aggregates, `trace.svg` and `results/figures/*.svg` the figures, and `results/manifest.json` the per-file SHA-256 map and canonical hash. The manifest's `metadata_excluded_from_canonical_hash` block holds the code SHA, package version, Python version, platform, and timestamp.
